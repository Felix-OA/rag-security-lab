# Knowledge Base Draft: Verification Troubleshooting

Draft ID: KB-DRAFT-441

## Common issue

Customers sometimes fail the in-app confirmation because their demo device clock is incorrect. Agents may explain how to reopen the application and retry once before using the formal Identity Review process.
